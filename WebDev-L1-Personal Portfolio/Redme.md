# 👨‍💻 Personal Portfolio Website

A clean and responsive personal portfolio website designed to showcase my skills, projects, background, and contact information.

This project was created as part of my web development internship to practice building a professional personal website using HTML5 and CSS3.

---

## 📌 Project Overview

The Personal Portfolio website works as a digital résumé and provides visitors with an overview of my technical skills, projects, background, and ways to get in touch with me.

The design focuses on keeping the interface simple, professional, readable, and responsive across different screen sizes.

---

## 🎯 Objective

The main objective of this project is to create a personal portfolio website that effectively presents:

- Personal introduction
- Professional role
- About section
- Technical skills
- Projects
- Contact information

The project also focuses on developing practical skills in webpage layout, responsive design, navigation, typography, and visual organization.

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Website structure and content |
| CSS3 | Styling, layout and responsiveness |
| Google Fonts | Typography |

No frontend framework is used in this project.

JavaScript is also not required for the core functionality.

---

## ✨ Features

### 1. Hero / Profile Section

The landing section introduces me to visitors and includes:

- Name
- Professional role
- Short introduction
- Profile photo / avatar
- Call-to-action elements

The section is designed to immediately communicate who I am and what I do.

---

### 2. About Me

The About section provides a short introduction about my background, interests, and goals.

It gives visitors additional context about my development journey and areas of interest.

---

### 3. Skills Section

A dedicated skills section displays my technical skills in an organized layout.

Example skills include:

- HTML
- CSS
- JavaScript
- React
- Node.js
- Git
- GitHub
- C / C++

The skill layout makes it easy for visitors to quickly identify the technologies I work with.

---

### 4. Projects Section

The Projects section showcases selected projects through individual project cards.

Each project card contains:

- Project title
- Short description
- Technologies used
- GitHub / project link

The section can be expanded as more projects are completed.

---

### 5. Contact Section

The Contact section provides ways for visitors to connect with me.

It can include:

- Name
- Email
- GitHub
- LinkedIn
- Other relevant social links

---

### 6. Smooth Navigation

Navigation links allow visitors to quickly move between different sections of the portfolio.

The page uses smooth scrolling to make movement between sections feel more natural.

---

### 7. Responsive Design

The portfolio is designed to work across different screen sizes, including:

- Desktop
- Laptop
- Tablet
- Mobile

CSS media queries and responsive layout techniques are used to adapt the design for smaller screens.

---

### 8. Consistent Branding

A consistent visual identity is maintained throughout the website using:

- Consistent colour palette
- Matching typography
- Reusable button styles
- Consistent spacing
- Similar card and section styling
