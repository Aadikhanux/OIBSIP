# 🌐 Landing Page

A clean, responsive, and visually polished landing page built using HTML5 and CSS3.

This project was created as part of my web development internship to demonstrate fundamental frontend development skills including page structure, responsive layouts, navigation, typography, spacing, and consistent visual design.

---

## 📌 Project Overview

The Landing Page is a static website designed to present a product, service, or brand in a simple and attractive way.

The page focuses on:

- Clean and structured layout
- Easy navigation
- Attractive hero section
- Clear call-to-action
- Responsive design
- Consistent colour scheme
- Readable typography
- Proper spacing and alignment

The project is built entirely with **HTML5 and CSS3**, without using JavaScript.

---

## 🎯 Objective

The main objective of this project is to build a visually polished static landing page while developing a strong understanding of:

- HTML page structure
- CSS styling
- Flexbox and responsive layouts
- Navigation bars
- Hero sections
- Content organization
- Buttons and call-to-action elements
- Typography
- Spacing and alignment
- Responsive web design

---

## 🛠️ Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Website structure and content |
| CSS3 | Styling, layout and responsiveness |

No JavaScript or external frontend framework is used in this project.

---

## ✨ Features

### 1. Fixed / Sticky Navigation Bar

The website includes a navigation bar that remains accessible while scrolling.

It contains links to different sections of the page, making navigation simple and user-friendly.

Navigation includes:

- Home
- Features
- About
- Contact

---

### 2. Hero Section

The hero section is the main introduction area of the website.

It includes:

- Main headline
- Supporting subheadline
- Call-to-action button
- Clean visual layout

The purpose of the hero section is to immediately communicate the main idea of the product or service.

---

### 3. Features Section

A dedicated section highlights the main features or benefits of the product/service.

Each feature is presented in a separate content block to make the information easy to scan.

---

### 4. About Section

The About section provides additional information about the brand, product, or service.

It helps visitors understand the purpose and value of the website.

---

### 5. Call-to-Action

The landing page contains clear call-to-action elements that encourage visitors to take the next step.

Examples include:

- Get Started
- Learn More
- Contact Us

---

### 6. Footer

The footer contains placeholder contact and social links.

It provides a simple ending to the webpage while keeping important links accessible.

---

### 7. Responsive Design

The website is designed to work across different screen sizes.

The layout adapts to:

- Desktop computers
- Laptops
- Tablets
- Mobile phones

CSS media queries are used to adjust spacing, font sizes, navigation, and content layout for smaller screens.

---

### 8. Consistent Design

A consistent visual style is maintained throughout the page using:

- A fixed colour palette
- Consistent typography
- Matching button styles
- Proper spacing
- Consistent borders and shapes
