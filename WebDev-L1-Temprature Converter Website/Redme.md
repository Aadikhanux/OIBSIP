# 🌡️ Temperature Converter Website

A simple and responsive temperature conversion tool that allows users to convert temperatures between Celsius, Fahrenheit, and Kelvin.

This project was created as part of my web development internship to practice JavaScript fundamentals, user input handling, validation, mathematical calculations, and DOM manipulation.

---

## 📌 Project Overview

The Temperature Converter is an interactive web application where users can enter a temperature value, select its unit, and convert it into the other supported temperature units.

The application provides immediate and easy-to-understand conversion results while handling invalid inputs and temperatures below absolute zero.

---

## 🎯 Objective

The main objective of this project is to build an interactive temperature conversion tool while developing practical knowledge of:

- HTML form elements
- CSS layouts
- JavaScript DOM manipulation

## ✨ Features

### 1. Temperature Input

Users can enter a numerical temperature value into the input field.

The application validates the entered value before performing any calculation.

---

### 2. Unit Selection

The user can select the input temperature unit from:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

The selected unit determines how the entered value is interpreted.

---

### 3. Temperature Conversion

The application converts the entered temperature into the supported units.

For example:

```text
Input:
25 °C

Result:
25 °C
77 °F
298.15 K
