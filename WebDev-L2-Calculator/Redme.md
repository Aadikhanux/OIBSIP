# 🧮 Calculator

A responsive browser-based calculator that performs basic arithmetic operations through a simple and user-friendly button interface.

This project was created as part of my web development internship to practice JavaScript fundamentals, event handling, DOM manipulation, arithmetic operations, conditional logic, and responsive CSS layouts.

---

## 📌 Project Overview

The Calculator is a fully functional web application that allows users to perform common arithmetic operations directly in the browser.

The calculator supports:

- Addition
- Subtraction
- Multiplication
- Division
- Decimal calculations
- Operator chaining
- Clearing the current calculation
- Deleting the last entered character

The project uses **Vanilla JavaScript** for all calculator functionality without relying on external libraries or frameworks.
